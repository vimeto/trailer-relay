# Changelog

## 0.1.0 — November 6, 2026

Initial research release: four articulated vehicles; seeded, certified tracks; partial driver-view observations; discrete and continuous controls; provider-neutral model harness and subscription CLI routes; sandboxed Python controllers; note-passing studies; recorded experiments and a buildless 3D replay explorer.

Release preparation adds explicit cohort/version checks, whole-study infrastructure exclusions, complete study-member validation, a corrected Sonnet cache-read rate, official price-source links, frozen evaluation manifests, reproducibility tooling and packaging. Historical raw records are retained; the article and editorial history are maintained separately.

Limitations: two core course sets, unequal model samples, route-dependent prompts/effort, exploratory unclustered statistics, and no matched retry-without-notes control. An RL interface is a documented extension path, not an implemented Gymnasium environment.
